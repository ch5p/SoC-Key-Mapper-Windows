# SoC Key Mapper

소드 오브 콘발라리아 PC용 비공식 키 매퍼입니다.

## 다운로드

[최신 Release에서 다운로드](https://github.com/ch5p/SoC-Key-Mapper-Windows/releases/latest)

별도 설치 없이 사용하려면 `Standalone-win-x64.zip`을 다운로드해 압축을 풀고 실행하세요.
