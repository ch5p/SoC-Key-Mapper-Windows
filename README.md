# SoC Key Mapper

소드 오브 콘발라리아 PC용 비공식 키 매퍼입니다.

## 다운로드

[최신 Release에서 다운로드](https://github.com/ch5p/SoC-Key-Mapper-Windows/releases/latest)

별도 설치 없이 사용하려면 `Standalone-win-x64.zip`을 다운로드해 압축을 풀고 실행하세요.

## 업데이트 내역

### v0.3.0

이번 업데이트는 **하나의 단축키에 여러 위치를 묶는 다중 매핑·순환 입력**을 중심으로 입력 안정성과 실행 UX를 개선했습니다.

#### 다중 매핑 · 순환 입력

- 동일 단축키에 최대 **4개 위치** 등록
- 순환 OFF: 등록 위치 **동시 입력**
- 순환 ON: `① → ② → ③ → ④` 순차 실행
- 키보드와 MButton/XButton/Wheel 등 마우스 단축키 지원
- 같은 단축키의 위치에 순번 배지를 표시하고 중복 매핑 토글 UI 개선

#### 순환 타이머 · 쿨다운

- 중간 순번은 **1.5초 idle reset**
- 마지막 순번 성공 후 **1초 cooldown**
- cooldown 중 같은 단축키 입력은 폐기되고 종료 후 `①`부터 재시작
- cooldown 동안 타이머 중앙 숫자는 마지막 순번 유지
- 입력 피드백은 `현재/전체` 형식으로 간결화

#### 편집 · 오버레이

- 단축키 입력 대기 중 빈 곳 클릭으로 즉시 취소
- 다른 매핑 클릭 시 해당 매핑 편집으로 바로 전환
- 하단·밀집 배치에서 지나치게 긴 leader line을 줄여 위치 확인 개선
- 고급설정 바깥을 클릭하면 설정창이 자연스럽게 닫히도록 개선

#### 실행 · 입력 안정성

- 공식 클라이언트에서도 게임 자동 실행 지원
- 게임 종료 시 매퍼 자동 종료 옵션 추가
- 일시정지·Alt+Tab·포커스 이탈 시 대기 입력 취소
- 실제 터치 직전 게임 창과 매퍼 상태 재검증
- 자동 시작 터치와 일반 매핑 터치의 중첩 방지
- 순환 상태 초기화 뒤 이전 비동기 입력이 상태를 다시 변경하는 race 방지

#### 업데이트 알림

- **v0.3.0부터** 이후 새 정식 버전의 업데이트 알림 지원
- 업데이트 버튼으로 최신 Release 페이지 이동
- 네트워크나 업데이트 서버 오류는 기존 앱 실행에 영향 없음
